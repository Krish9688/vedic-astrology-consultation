# astrology-consultation engine

The local calculation core and service behind the `astrology-consultation` Claude plugin: Swiss Ephemeris positions,
16 divisional charts, Vimshottari to the third level, transits and exact slow-planet contacts, Shadbala, Ashtakavarga,
Jaimini factors, Sripati bhavas and a birth-time sensitivity grid, served over MCP (`astro mcp`), REST (`astro serve`)
and the `astro` command line. Private by default: no calculation leaves the computer.
